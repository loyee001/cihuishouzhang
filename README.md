# 词汇手账

「纸张手账」风格的本地英语学习网页。无需安装依赖；需要 Node.js 18 或更新版本。

## 启动

```bash
git clone https://github.com/loyee001/cihuishouzhang.git
cd cihuishouzhang
npm start
```

打开 http://localhost:4180。服务仅监听本机地址。

如果 4180 端口被占用，可用 `PORT=4181 npm start`，并打开相应地址。

## 已实现

- 词书选择：页面上方点击“换一本”，选择 Think 1（36词样章精选）、新概念英语1（第1–4课精选30词）、新概念英语2（第1–3课精选28词）、基础英语（24词原创主题精选）、日常交流（24词原创主题精选）。
- 各书分别保留章节、卡片位置、已学词、错词和默写记录；宠物成长与成就累计所有词书。
- 练习进行时先完成或结束练习再换书，避免丢失默写答案。旧版 Think 1 本地记录自动兼容，无需清空或重新学习。

- 单词新学：英文、中文、原创例句、系统语音朗读、逐词学习、词表跳转、待复习记录。
- 单词游戏：六对中英配对、五题词义挑战；错误反馈及成长奖励。
- 默写批改：看中文写英文、听音写英文；5/10/20/全部词、已学词、待复习词；批改、错词重练、每本词书最近30次记录。未提交答案保留在当前标签页，刷新后可继续。
- 我的宠物：改名、学习奖励、小点心喂养、升级、学习成就。
- 桌面及手机布局、键盘操作和减少动画偏好。

学习记录保存在当前浏览器的 localStorage；不跨设备同步。清除浏览器网站数据会清除记录。发音使用设备内置的 Speech Synthesis 英语语音，是否可以离线朗读取决于系统是否安装相应语音包。

## 词库范围与来源

教材词书内置 **Think Second Edition Level 1（英式版）Unit 1 公开样章精选 36 词**。词条核对范围为印刷页12–15，包含课文、词汇与活动中的词，部分词统一为词典原形；这不是完整单元或全册官方词表。

- Cambridge 官方目录：https://cambridgelatamcatalogue.org/product/think_second_edition/
- Cambridge 样章的分销商镜像（ISBN 9781009151931）：https://oxico.sk/lg/aj/assets/ukazky/think_2nd_1.pdf
- 中文释义、英文例句及例句翻译为学习辅助原创内容，不复制教材例句。
- `data.js` 保留每词出处页码和栏目，后续可以依据完整教材词表补充其他单元。
- 本网页为独立学习辅助工具，不是 Cambridge 官方产品。

新概念英语采用经典版（非青少版），当前为开头课次精选，不是全册或出版社官方词库。第一册第1–2课16词、第3–4课14词；第二册第1课12词、第2–3课16词。词条依据新东方、沪江的公开讲解核对，中文释义和例句原创；`textbooks.js` 中保留每词原课次和来源，页面“词表说明”可查看各课链接。部分新东方在线旧链接可能跳转，可按课次核对。

批改忽略大小写、首尾空白、多余连续空格；不会把拼写近似词自动算对。按词库中的英式拼写判分（例如 practise）；如需允许变体，可在词条中添加 `accept` 数组。

基础英语与日常交流为自主选词的主题词书，不是教材或考试的官方完整词表。词库注册在 `books.js`，新增词书时各书、章节、单词 ID 必须保持全局唯一。
